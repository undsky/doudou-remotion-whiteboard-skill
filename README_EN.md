## 📖 Skill User Guide

This skill library acts as a **hand-drawn whiteboard motion graphics engine for AI Agents and Remotion video projects** (natively supports Antigravity, Claude Code, OpenCode, and other platforms).

---

### 1. Installation

Install with a single command in any target project root directory:

```bash
npx skills add undsky/doudou-remotion-whiteboard --yes
```

---

### 2. Usage

You can prompt AI Agents directly in natural language to generate whiteboard animation videos:

- **Technical Architecture & Flow Derivation**:
  ```text
  Create a microservice architecture evolution video in hand-drawn whiteboard style, using a real hand holding a pen to sketch service nodes and invocation arrows, with cross-hatch shading highlights.
  ```
- **Academic Lectures & Blackboard Derivations**:
  ```text
  Use a textured dark green blackboard paper background with chalk drawing dynamics to derive the Attention mechanism formula, highlighting key parts with hand-drawn oval circles.
  ```
- **Business Commentary & Product Evolution**:
  ```text
  Use warm creamy sketch paper as the base canvas, with a real right hand drawing a business model evolution scroll, featuring hand-drawn cross-hatch shading and underlined emphasis at key milestones.
  ```

## 🎨 Core Capabilities

| Core Module | Key Features & Applications |
|---|---|
| **Physical Brush & Real Hand Following** | Pen tip anchor alignment (0, 0), smooth tangential turning, lift/press height dynamics (`liftHeight`), 3D depth shadow diffusion |
| **Hand-Drawn Shapes & Connectors** | Parametric micro-jitter, rectangles/circles/stars, dual-wing hand-drawn arrows, circle highlights, and scratch-out erasers |
| **Sketch Shading & Cross-Hatch Fill** | Simulates polygon scanline algorithms, supporting single-direction hachure and cross-hatch shading for authentic sketch textures |
| **Handwritten Text & Character Streaming** | Stroke-by-stroke transparency bleeding, real-time feedback of streaming coordinates for pen tip hovering and writing |
| **Multi-Texture Paper & Canvas Containers** | Built-in creamy sketch paper (`sketch`), engineering blueprint grid (`blueprint`), textured blackboard (`chalkboard`), kraft paper (`kraft`), and pure whiteboard |
