## 📖 技能使用指南

本技能库作为 **AI Agent 与 Remotion 视频工程的手绘白板动效引擎**（原生支持 Antigravity、Claude Code、OpenCode 等平台）。

---

### 一、安装

在任何目标工程根目录下，通过命令行一键安装：

```bash
npx skills add undsky/doudou-remotion-whiteboard --yes
```

---

### 二、使用

可以直接通过大白话让 AI Agent 生成手绘白板视频：

- **技术架构与流程推导**：
  ```text
  帮我用手绘白板风格制作一段微服务架构演进视频，用真人握笔画出服务节点与调用箭头，并加上排线阴影高亮
  ```
- **学术讲座与黑板推演**：
  ```text
  用磨砂深绿黑板底纸和粉笔运笔动效，推导演讲注意力机制公式，重点部分做手绘椭圆划圈高亮
  ```
- **商业解说与产品演进**：
  ```text
  用米白素描纸作为底图，真人右手持笔画出商业模式演进长卷，关键节点带有手绘排线阴影与下划线强调
  ```

## 🎨 核心能力

| 核心模块                 | 核心特性与应用                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------- |
| **物理笔刷与人手跟随**   | 笔尖锚点对齐 (0, 0)、行进切线平滑转向、抬笔/落笔高度动力学 (`liftHeight`)、3D 深度投影扩散                    |
| **手绘几何与架构连接**   | 参数化微颤抖动、矩形/圆/星形、双翼手绘箭头、划圈划重点与涂抹擦除效果                                          |
| **素描排线与阴影填充**   | 模拟多边形扫描线算法，支持单向斜排线与双向十字交叉排线，呈现纯正手绘速写阴影                                  |
| **手写文本与字符流显现** | 逐笔逐字切片透明度渗透，实时回传字流末端坐标供笔尖悬停跟随书写                                                |
| **多材质底纸与画布容器** | 内置米白素描糙纸 (`sketch`)、工程蓝图网格 (`blueprint`)、磨砂黑板 (`chalkboard`)、牛皮纸 (`kraft`) 与纯净白板 |
